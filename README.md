## Project Information
Chat App where people can speak to each other and part 1 is the user login and registration Section, which includes the messaging feature, you can send and show messages that has been stored

## Features
### Regstering user
User register to the system

### Login User
User can login again if they registered already.

### Validation 
Validates details about the user that have been entered.

### Send Messages
User can send messages by inputting the recipients number and ensuring that it is less than 250 words.

### Messages validations
Messages needs to meet certain criteria for it to work by ensuring that the messageID is the correct length and the recipients number is the correct code.

### Storing messages
If users don't want to send messages they can store and when they return to the program they see messages that have been stored.
